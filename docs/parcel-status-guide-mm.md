# ပါဆယ် အခြေအနေ လမ်းညွှန်စာ
### Royal's Myawaddy Delivery System — ပါဆယ်စနစ် အသုံးပြုသူ လမ်းညွှန်

---

## အခြေအနေစနစ် အကြောင်း

ပါဆယ်တစ်ခုသည် အောက်ပါ အခြေအနေများကို ဖြတ်သန်းပါသည်—

```
RECEIVED → VERIFIED → IN_TRANSIT → DELIVERED
                              ↘ FAILED
                              ↘ DAMAGED
```

- **RECEIVED** — မြဝတီရုံးသို့ ရောက်ရှိကြောင်း အတည်ပြုပြီး
- **VERIFIED** — ပါဆယ်စစ်ဆေးပြီး
- **IN_TRANSIT** — ပို့ဆောင်နေဆဲ
- **DELIVERED** — ပို့ဆောင်ပြီးစီး (Terminal)
- **FAILED** — ပို့ဆောင်မအောင်မြင်
- **DAMAGED** — ပျက်စီး/ပျောက်ဆုံး (Terminal)

---

## အခြေအနေ အစီအစဉ် ဇယား

| လက်ရှိအခြေအနေ | ► ပြောင်းနိုင်သောအခြေအနေများ |
|----------------|-------------------------------|
| `RECEIVED` | `VERIFIED` · `DAMAGED` |
| `VERIFIED` | `IN_TRANSIT` · `DELIVERED` · `FAILED` · `DAMAGED` |
| `IN_TRANSIT` | `DELIVERED` · `FAILED` |
| `FAILED` | `IN_TRANSIT` · `DELIVERED` |
| `DELIVERED` | — (ဆုံးနှင့်ပြီ) |
| `DAMAGED` | — (ဆုံးနှင့်ပြီ) |

> **Terminal Statuses** — `DELIVERED`, `DAMAGED` (နောက်ထပ် မပြောင်းနိုင်တော့ပါ)

---

## အခြေအနေ တစ်ခုချင်း ရှင်းလင်းချက်

### `RECEIVED` — လက်ခံရရှိပြီ
- **အဓိပ္ပာယ်**: မြဝတီရုံးသို့ ရောက်ရှိကြောင်း အတည်ပြုပြီး
- **မည်သူ လုပ်သနည်း**: မန်နေဂျာ သို့မဟုတ် Admin
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: `VERIFIED`, `DAMAGED`

### `VERIFIED` — စစ်ဆေးပြီး
- **အဓိပ္ပာယ်**: ပါဆယ်စစ်ဆေးပြီး
- **မည်သူ လုပ်သနည်း**: မန်နေဂျာ သို့မဟုတ် Admin
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: `IN_TRANSIT`, `DELIVERED`, `FAILED`, `DAMAGED`

### `IN_TRANSIT` — ပို့ဆောင်နေဆဲ
- **အဓိပ္ပာယ်**: ဝန်ထမ်းသို့ သတ်မှတ်ပြီး ပို့ဆောင်နေဆဲ
- **မည်သူ လုပ်သနည်း**: ပို့ဆောင်ရေးဝန်ထမ်း
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: `DELIVERED`, `FAILED`

### `DELIVERED` — ပို့ဆောင်ပြီးစီး
- **အဓိပ္ပာယ်**: လက်ခံသူထံ အောင်မြင်စွာ ပို့ပြီး
- **မည်သူ လုပ်သနည်း**: Admin, Manager, Delivery Staff
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: မရှိ

### `FAILED` — ပို့ဆောင်မအောင်မြင်
- **အဓိပ္ပာယ်**: ပို့ဆောင်မအောင်မြင်
- **မည်သူ လုပ်သနည်း**: Delivery Staff
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: `IN_TRANSIT`, `DELIVERED`

### `DAMAGED` — ပျက်စီး/ပျောက်ဆုံး
- **အဓိပ္ပာယ်**: ပါဆယ် ပျက်စီး သို့မဟုတ် ပျောက်ဆုံး
- **မည်သူ လုပ်သနည်း**: Admin, Manager
- **နောက်ထပ် ဖြစ်မည့်အခြေ**: မရှိ
